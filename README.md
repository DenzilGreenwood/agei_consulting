# CognitiveInsight.ai | AI Governance Evidence Infrastructure (AGEI)

Welcome to the official repository for **CognitiveInsight.ai**, representing the enterprise reference library and technical front-end for the **AI Governance Evidence Infrastructure (AGEI)** and the **Cognitive Insight Audit Framework with Lazy Capsule Materialization (CIAF-LCM)**.

This repository serves as both the public-facing consultancy interface and the developer documentation hub for implementing cryptographically verifiable "Proof, Not Logs" AI governance.

## 🏛️ Architecture & Tech Stack

This project is built using modern web development standards to ensure a premium, responsive, and maintainable enterprise footprint:
- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** Tailwind CSS (Custom enterprise theme defined in `globals.css`)
- **Icons:** Lucide React
- **Typography:** Modern Sans-Serif stack (Inter/Outfit style approach)

## 🚀 Getting Started

To run the CognitiveInsight.ai frontend locally:

1. **Install Dependencies:**
   Navigate to the frontend directory and install the Node modules.
   ```bash
   cd agei_frontend
   npm install
   ```

2. **Run the Development Server:**
   ```bash
   npm run dev
   ```

3. **View the Application:**
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
